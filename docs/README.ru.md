# Claude Code Usage Monitor — описание форка

[English README](../README.md)

## О форке

Claude Code Usage Monitor располагается на панели задач Windows, позволяя отслеживать активные лимиты квот ИИ, таймеры сброса и окна использования по нескольким аккаунтам и сервисам в одном месте.

Этот проект — независимый форк [CodeZeno/Claude-Code-Usage-Monitor](https://github.com/CodeZeno/Claude-Code-Usage-Monitor). Мы искренне благодарим автора оригинала, Code Zeno, чья отличная работа и проект под лицензией MIT сделали это возможным. Форк развивается независимо по адресу [fix2it/Claude-Code-Usage-Monitor](https://github.com/fix2it/Claude-Code-Usage-Monitor) с упором на мониторинг нескольких профилей, компактность на панели задач, раздельные настройки виджетов и скорость отрисовки.

## Чем форк отличается от оригинала

1. **Отдельные виджеты для пулов разных профилей и переключатель «Пулы на одном виджете»:** Чтобы видеть пул каждого аккаунта отдельно, в форке добавлены отдельные виджеты для пулов Claude (Claude / Claude X), Codex (Codex / Codex X) и Antigravity (A / O) с пунктом меню для объединения их в одну плитку или разделения на отдельные плитки для одновременного наблюдения.

2. **Второй пул Antigravity (пул O) из токена OpenCode:** Пользователям, работающим с Antigravity напрямую и через OpenCode, требовалось видеть обе квоты, поэтому добавлен опрос пула O в режиме «только чтение» из сохранённого токена OpenCode рядом с пулом A, что позволяет видеть оба лимита рядом без повторного входа.

3. **Отслеживание Fable для каждого пула Claude:** Так как расход Fable учитывается отдельно, каждый пул Claude получил свою строку Fable с 5-кубиковыми шкалами и засечками темпа, обеспечивая раздельный контроль по каждому профилю рядом со стандартными 5-часовыми и недельными окнами.

4. **Раздельные компактные режимы отображения виджетов:** Разным провайдерам требуется разный уровень детализации, поэтому виджеты получили три компактных режима (переключаемых кликом или колесом мыши), позволяя настраивать баланс текста и ширины шкал для каждой плитки отдельно или зажав Shift для всех сразу.

5. **Иерархическое контекстное меню:** По мере добавления настроек профилей и моделей меню было организовано в древовидную структуру — параметры Fable вложены в пулы Claude, а внешние модели в пулы Antigravity, — что позволяет быстро находить и настраивать нужные опции без визуального шума.

6. **Адаптивная ширина виджетов:** Чтобы исключить обрезание чисел или лишние пустые отступы, ширина виджетов измеряется динамически по активному тексту и кэшируется, занимая на панели задач ровно столько места, сколько требуется текущим данным.

7. **Засечки темпа расхода на шкалах квот:** Сам по себе процент не показывает, опережает ли расход время окна, поэтому опциональная засечка отмечает прошедшее время на шкале, сразу показывая, если квота расходуется с опережением расписания сброса.

8. **Интеграция провайдера Qoder:** Поскольку у Qoder нет публичного REST API, фоновый поллер опрашивает `qodercli /usage` не чаще раза в 15 минут, выводя основной план и кредиты на панель задач с переключением по наведению и засечками для 30-дневного окна.

9. **Обновлённая поддержка OpenCode Go:** Для работы с актуальным API консоли OpenCode и отображения недельного и месячного лимитов запросы передают обязательный заголовок авторизации bearer, а шкалы плавно переключаются по наведению курсора, объединяя оба периода в одной плитке.

10. **Собственные обновления и защита исполняемого файла:** Чтобы сборки апстрима или WinGet не перезаписывали форк, а сбой обновления не повредил программу, встроенный апдейтер обращается к репозиторию форка, использует версионирование в номере патча (например, `2.23.601`) и сохраняет рабочий файл при ошибках перезаписи.

11. **Оптимизация отрисовки и неблокирующий интерфейс:** Чтобы убрать лишнюю нагрузку на кадр и зависания интерфейса, версия 2.23.602 кэширует темы и настройки темного режима, повторно использует буферы, выносит сохранение настроек из-под блокировки и использует неблокирующий `Present(0)` — кадры отрисовываются на 30–36 % быстрее (замер для v2.23.602), а интерфейс остаётся отзывчивым.

12. **Сфокусированная тема и облегчённый код:** Поскольку задача форка — специализированный виджет для панели задач, Theme Studio и остальные встроенные темы были убраны в пользу единой выверенной темы **Compact Fluent Quad** (с сохранением поддержки внешних JSON-тем), что сделало приложение легче и проще в поддержке.

13. **Аудит кодовой базы и повышение стабильности:** Для устранения краевых ошибок (вроде ложных 0% квоты) и разгрузки функций-гигантов многораундовый аудит (`audit-ledger.md`) разделил ключевые подсистемы на модульные шаги и исправил найденные недочёты, обеспечив точные статусы в подсказках и понятную структуру кода.
