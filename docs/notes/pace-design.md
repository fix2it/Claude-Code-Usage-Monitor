# Темп (pace) на шкалах виджета — дизайн (2026-10-18, кода нет)

## Решение владельца (финальное)
- Только тема Compact (compact-fluent-quad). Classic и прочие темы не трогаем.
- Вариант A: засечка на шкале «где расход должен быть сейчас». Других правил (число темпа, метки,
  отдельное поведение для расширенного виджета) нет.
- Прогноз «когда кончится» не показывать.
- Изменения для Classic (общий `antigravity.*`, следующий выбранному пулу) отменены 2026-10-18:
  в Classic `antigravity.*` снова всегда Gemini.

## Расчёт
- expected_used = доля прошедшего времени окна × 100; прошло = длина окна − (reset − now).
- Длина окна: 5h = 5 ч, weekly = 7 дней (для agy тоже 7 дней, подтверждено владельцем). История не нужна.
- Нет окна или нет resets_at → засечки нет.
- Режим «осталось»: засечка ставится на 100 − expected.

## Справочно (в виджете не используется)
- limits.py при остатке < 5% показывает "attention" («внимание»).

## Реализация (план)
- Движок: поле `{window}.expected` для каждого окна.
- compact-fluent-quad: засечка отдельным объектом с `x` = ширина шкалы × expected / 100 (x уже задаётся выражением),
  цвет — основной цвет текста темы (видна в светлой и тёмной).
