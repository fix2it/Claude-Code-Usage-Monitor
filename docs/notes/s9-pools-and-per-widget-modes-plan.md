## Этап 1. Шкала не длиннее 5 кубиков

- Верхняя граница числа кубиков — 5 во всех режимах и при любом числе виджетов.
- Столбец Fable получает те же размеры, что остальные, и входит в подсчёт числа виджетов.

Готово, когда: тесты метрик проверяют 1, 2, 3 и больше виджетов, с Fable и без;
ни в одном случае кубиков не больше 5; ширина виджета не «прыгает» при
включении Fable сильнее, чем при включении любого другого виджета.

## Этап 2. Fable для обоих Claude

Подэтапы:

- **2a. Данные.** Fable разбирается для каждого пула отдельно, ключи кэша добавлены. Виджеты не меняются. Тесты на разбор и кэш.
- **2b. Один пул.** Fable — третья строка в виджете Claude; старый столбец Fable в этом случае убран.
- **2c. Два пула.** Виджет Fable в две строки, строка на пул; подсказки и риски темпа.

Требования:

- Разбор `weekly_scoped` с моделью Fable работает для обоих пулов, значения лежат отдельно по пулу.
- Два пула активны: Fable — отдельный виджет в две строки, строка на пул (шкала + цифры), как основной виджет Claude.
- Один пул активен: Fable — третья строка в виджете Claude, отдельного столбца нет.
- Нет данных Fable у пула — его строка показывает «нет данных», а не чужое значение.
- Кэш `usage-cache.json`: новые ключи только добавляются, старые не меняются (их читает `limits.py`).

Готово, когда: тесты покрывают оба пула, один пул, отсутствие Fable у одного из
пулов; подсказки и риски темпа работают в новых строках; владелец принял вид на
сборке.

## Этап 3. Режим у каждого виджета свой

Подэтапы:

- **3a. Состояние и настройки.** Режим на виджет, миграция старого `view_mode`, ширина окна по режимам каждого виджета. Ввод пока меняет всех сразу, как сейчас.
- **3b. Ввод и анимация.** Клик и колесо по виджету под курсором, Shift — все; анимация только у меняющегося виджета.

Требования:

- В настройках — режим на виджет (ключ по id виджета); старое поле `view_mode` читается как значение по умолчанию для всех.
- Клик и колесо меняют режим только виджета под курсором. С Shift — всех.
- Анимация перехода идёт только у меняющегося виджета; остальные не перерисовываются зря.
- Ширина окна считается как сумма виджетов в их собственных режимах.

Готово, когда: тесты на миграцию старой настройки, на клик / колесо / Shift, на
ширину окна при смешанных режимах; сохранённые режимы восстанавливаются после
перезапуска; счётчик пересчёта метрик из s8 не вырос на кадр.

Риск: сейчас один общий скаляр `mode_phase`. Если разведка покажет, что его
читают тема и хит-тест во многих местах, 3a делится ещё раз: сначала теме
передаётся скаляр на виджет, затем настройки и ширина.

## Этап 4. Меню: второй уровень

Подэтапы:

- **4a. Контекстное меню виджета.** Вложенные пункты, перенос «Fable», видимость по родителю.
- **4b. Окно настроек и переводы.** То же в списке провайдеров настроек, строки во всех 14 языках.

Требования:

- Под Claude — «Fable»; под agy — «Внешние модели». Пункты с отступом, видны только при включённом родителе.
- Старый пункт «Показывать Fable» из общего меню убирается; настройка `show_fable` и её значение сохраняются.
- То же в окне настроек, если список провайдеров там дублируется.
- Строки добавляются во все 14 языков.

Готово, когда: выключение родителя прячет дочерний пункт, но не сбрасывает его
значение; тесты меню обновлены.

## Этап 5. Второй пул agy

Ждёт папку `~/.gemini_x` от владельца.

Подэтапы:

- **5a. Данные.** Опрос второй папки, ключи кэша с суффиксом `_x`. Виджеты не меняются.
- **5b. Раскладка.** Строки второго пула в виджетах agy по двум вариантам ниже.

Требования:

- Опрос второго аккаунта по источнику токена, найденному на этапе 0, теми же запросами; учётные данные не меняются и не обновляются. Если источник второго аккаунта совпадает с первым (тот же токен) — второй пул не показывается, чтобы не выводить квоту первого аккаунта дважды; это проверяется тестом.
- Внешние модели включены: как сейчас, два виджета (Gemini и внешние), в каждом по строке на пул.
- Внешние модели выключены: оба пула agy на одном виджете, две строки.
- Ключи кэша: `antigravity` остаётся как есть; для второго пула — новые ключи с суффиксом `_x`.

Готово, когда: без `~/.gemini_x` поведение ровно как сейчас; с ней — тесты на оба
варианта раскладки; `limits.py` продолжает работать без правок.

## Этап 6. Галочка «Пулы на одном виджете»

- Пункт второго уровня у Claude и agy, виден только когда найдено два пула.
- Включена (по умолчанию, как сейчас): пулы строками в одном виджете. Выключена: каждый пул — свой виджет со своим режимом.
- Fable следует настройке Claude.

Готово, когда: тесты на оба положения для Claude и agy; число виджетов для
этапа 1 считается с учётом разделения.

## Порядок и зависимости

0 → 1 → 2a → 2b → 2c → 3a → 3b → 4a → 4b → 5a → 5b → 6. Этап 4 можно сделать раньше этапа 3, они не
пересекаются по файлам. Этап 5 не блокирует остальные: если папки `~/.gemini_x`
ещё нет, этап 6 делается сначала только для Claude.
